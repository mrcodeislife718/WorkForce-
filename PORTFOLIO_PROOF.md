# WorkForce — Portfolio Proof Contract

**Track:** Commercial persistent AI-worker / agent infrastructure

WorkForce is complete only when persistent workers execute real workflows reliably across state, tools, retries, concurrency, verification, and recovery, and create measurable customer value.

Required proof: runnable worker lifecycle; tests for state, idempotency, collisions, tool authorization, retries, memory, and completion verification; fault injection for process/network/provider/tool failures and duplicate work; benchmarks for task success, latency, recovery, cost, concurrency, and long-run stability; tenant/security controls; production deployment; real users; paid usage and retention where commercialized.

Every claim must map to a command or artifact. Agent self-reporting is never sufficient proof of task completion.

**Next proof target:** execute a multi-worker workload with forced crashes, duplicate triggers, tool failures, and restarts; verify exactly-once/controlled-retry behavior and preserve task/evidence ledgers.
